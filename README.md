# Домовой - Сайт студии детских праздников

Профессиональный сайт для организации детских праздников в Бельцах, Молдова.

## 🎯 Особенности

- **Персонажи-аниматоры и дополнительные форматы** (Трансформеры, ростовые куклы, батуты) с отдельными страницами
- **Контактная форма** с интеграцией Telegram Bot
- **Галерея мероприятий** с фото и видео
- **Адаптивный дизайн** (mobile-first)
- **Статическая генерация** для максимальной производительности
- **SEO-оптимизация** всех страниц

## 🛠 Технологии

- **Next.js 15.4.10** (App Router)
- **TypeScript 5.x**
- **Tailwind CSS v4**
- **React Hook Form** + **Zod** (валидация форм)
- **Axios** (Telegram API)

## 📦 Установка

1. Клонируйте репозиторий:
\`\`\`bash
git clone <repository-url>
cd celebrate-agency
\`\`\`

2. Установите зависимости:
\`\`\`bash
npm install
# или
yarn install
\`\`\`

3. Создайте файл \`.env.local\` на основе \`.env.example\`:
\`\`\`bash
cp .env.example .env.local
\`\`\`

4. Заполните переменные окружения в \`.env.local\`:
\`\`\`env
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_USER_IDS=user_id_1,user_id_2
\`\`\`

## 🚀 Запуск

### Режим разработки:
\`\`\`bash
npm run dev
\`\`\`
Сайт будет доступен по адресу: http://localhost:3000

### Production build:
\`\`\`bash
npm run build
npm start
\`\`\`

## 🖼️ Изображения

### Текущее состояние
Все изображения - это **JPG placeholder'ы** с правильными размерами. Они готовы к замене на реальные фотографии.

### Замена изображений
1. Подготовьте фотографии в нужных размерах:
   - **Hero:** 1920x600 px
   - **Услуги:** 800x600 px (основное фото и 6 фото галереи на каждую)
   - **События (featured):** 1200x675 px
   - **События (галерея):** 800x600 px

2. Сохраните с теми же именами файлов
3. Поместите в соответствующие папки в \`public/images/\`

Подробности см. в \`IMAGE-PLACEHOLDERS.md\`

### Регенерация placeholder'ов
Если нужно пересоздать placeholder изображения:
\`\`\`bash
node scripts/generate-jpg-placeholders.js
\`\`\`

## 📝 Обновление контента

### Добавление нового персонажа или формата:

1. Откройте \`src/data/services.json\` и добавьте запись в конец списка.
   - Обязательные поля: \`id\`, \`name\` (ru/ro), \`slug\` (только латиница, цифры и дефис, без румынских букв), \`description\` (ru/ro), \`image\`, \`gallery\`, \`color\`, \`ageRange\` (ru/ro, например "3-12 лет").
   - Необязательные поля: \`price\` (число в lei), \`priceOnRequest\` (показать «Цена по запросу»), \`priceNote\` (подпись к цене), \`hideOffer\` (не выводить цену в JSON-LD), \`duration\` (ru/ro), \`content\` (блоки текста страницы с заголовками H3 и списками).
2. Добавьте изображения в \`public/images/services/\`: \`<slug>.jpg\` и \`<slug>-gallery-1.jpg\` ... \`<slug>-gallery-6.jpg\`.
3. Добавьте SEO-записи (title, description, секции H2/H3) для обоих языков в \`src/messages/ru/seo/services-by-slug.json\` и \`src/messages/ro/seo/services-by-slug.json\`.
4. Страница услуги и записи sitemap создаются автоматически. Пересоберите проект (\`npm run build\`) и запустите \`npm run verify:seo\`.

### Добавление события:

1. Откройте \`src/data/events.json\`
2. Добавьте новое событие:
\`\`\`json
{
  "id": "4",
  "title": "Название события",
  "slug": "nazvanie-sobytiya",
  "date": "2024-04-15",
  "featuredImage": "/images/events/event-4-featured.jpg",
  "images": ["/images/events/event-4-1.jpg"],
  "youtubeUrl": "https://www.youtube.com/watch?v=...",
  "description": "Описание события"
}
\`\`\`
3. Добавьте изображения в \`public/images/events/\`
4. Пересоберите проект

### SEO-блок и H1:
- SEO-тексты лежат в \`src/messages/{ru,ro}/seo/*.json\`. Блок всегда раскрыт (сворачивания и кнопки нет).
- Уровень секции: 2 или 3 для всех страниц. Уровень 1 (\`h1\`) используется только в \`seo/home.json\`: это единственный H1 главной, он стоит первой секцией блока.
- В \`Hero.tsx\` заголовок это обычный \`p\`, не заголовок. H1 главной не добавляйте в баннер.
- \`npm run verify:seo\` проверяет один H1 на странице (A17), текст H1 главной (A18), раскрытый SEO-блок (A21) и отсутствие румынских ключевых фраз на русских страницах (A22).

### Главный баннер:
- Компонент \`src/components/hero-banner/HeroBanner.tsx\`: цикл 12 с из трёх сцен (CSS и два canvas на \`engine.ts\`), без видеофайлов, RU и RO.
- В баннере нет заголовков h1-h6. Заголовок, подзаголовок и кнопка (\`hero.title\`, \`hero.subtitle\`, \`hero.ctaText\` в \`home.json\`) рендерятся только на клиенте и в серверный HTML не попадают. Две серверные строки: \`hero.kicker\` и \`hero.note\`.
- Высота: 560 px на мобильном, 600 px на десктопе; верхние 80 px закрывает фиксированная шапка.
- Пауза вне экрана и на скрытой вкладке, статичный кадр при \`prefers-reduced-motion\`, облегчённый режим при FPS ниже ~30. Кнопки паузы нет.
- Старые \`Hero.tsx\` и \`public/images/hero/hero-bg.jpg\` оставлены для отката: вернуть импорт \`Hero\` в \`home-page.tsx\`.
- \`npm run verify:seo\` проверяет: нет h1-h6 в баннере (A19), серверный HTML содержит две строки и не содержит клиентские тексты (A20).
